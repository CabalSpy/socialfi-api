# Changelog

All notable changes to socialfi-api (npm and PyPI) are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow `cabalspy-id`.

## [0.6.0] - 2026-10-28

### Added

- White-label (platform users) and trading competitions, from `cabalspy-id` 0.6.0: import your users and their existing wallets by your own user id, their profiles, PnL and leaderboards, and competitions between them. See the [White-Label docs](https://docs.cabalspy.xyz/cabalspy-id/white-label).

### Changed

- Requires `cabalspy-id` 0.6.0.

## [0.5.0] - 2026-10-14

### Added

- First release: `socialfi-api` on npm (re-exports `cabalspy-id/api`) and PyPI (re-exports `cabalspy_id.api`).
